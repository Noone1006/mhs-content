# My Hospital Support — live content

This repository holds **content.json**, which the *My Hospital Support* app reads
each time it opens. Editing this file changes what patients see — **without needing
an app update**.

- **banners** — the coloured messages at the top of a hospital's screen.
- **notices** — the picture cards on the Notice Board.
- **wardInfo** — each ward's specialty, location, phone number and visiting
  times, mirrored from the trust's own website.

Changes appear in the app within a few minutes of being saved here.

> Keep `content.json` as valid JSON. The easiest way to change it is to ask Claude,
> or use the Banner/Notice tools — they keep the format correct for you.

## Rules for wardInfo

- It is generated by a scan tool in the app project that mirrors the trust's
  ward pages. **Scan output is always reviewed by a human before it is
  committed here** — see the app repo's `WARD-INFO-NOTES.md` for the routine
  and for known trust-page errors that must not be "corrected" back.
- Ward names must exactly match the app's ward list — that's how the app finds
  each ward's details.
- An **empty** `"wards": []` is an intentional retraction of all ward info
  (running apps drop it within minutes); deleting the whole `wardInfo` key
  instead keeps each app's last-known-good copy.
- Phone numbers are digits and spaces only. The app rejects anything else,
  including premium-rate prefixes.
- Never add AccessAble content — it is licensed material and the app only
  links to it.

_The app treats this file as untrusted and validates everything: invalid
entries are silently dropped, so a typo can't crash the app — it just
disappears until fixed._
